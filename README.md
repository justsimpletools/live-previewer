# Markdown Preview

A focused React + Vite application for writing Markdown and seeing a live rendered preview. GitHub-flavored Markdown is supported through `react-markdown` and `remark-gfm`.

## Getting started

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build:

```bash
npm run build
npm run preview
```

## Features

- Live Markdown editing and rendering
- GitHub-flavored Markdown (tables, task lists, strikethrough, and more)
- Responsive two-column editor layout
- Character count and accessible editor labeling
- Tailwind CSS tooling with a custom editorial visual style

## Project structure

- `src/App.tsx` — editor and rendered preview
- `src/index.css` — Tailwind directives and application styling
- `docs/` — original project notes
